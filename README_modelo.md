# rfbmodel1D

A 1-D, transient DAE model of a full **H₂–V regenerative redox flow battery (RFB)** cell,
coupling hydrogen anode kinetics, vanadium cathode electrochemistry, and membrane water/proton
transport. The model is fit against experimental polarization (E-cell) and high-frequency
resistance (HFR) data and used to decompose overpotential contributions across operating
conditions (state of charge, catholyte flow rate, temperature).

## Repository structure

```
rfbmodel1D/            Core package: cell/subdomain models, DAE residuals, electrochemistry, meshing
scripts/
  Validation/          Conservation checks, mesh-convergence studies, single-run CLI
  utils/               Simulation helpers used by the notebooks
  functions/           Shared standalone models (membrane diffusion, current density)
notebooks/
  plotting/               Notebooks that generate the paper's figures
  parameter_sensitivity/  Sensitivity analyses and overpotential breakdown
data/experimental/     Experimental datasets used for fitting/validation, with sources documented
results/test fitting/  Fitted parameters (per-test HFR fits, global cathode/anode kinetics fits)
figures/               Output directory for figures generated by the notebooks
tests/                 Unit tests
setup.py
```

## Installation

Requires Python 3.10+.

```bash
git clone <this-repo-url>
cd rfbmodel1D
pip install -e .
```

## Quick start

Run a simulation from the command line:

```bash
python scripts/Validation/run_simulation.py --tf 10 --soc 0.8 --rtol 1e-4 --out my_run
```

This writes `my_run.npz`, loadable with:

```python
import numpy as np
data = np.load("my_run.npz")
tsol = data["tsol"]   # time points [s]
ysol = data["ysol"]   # state vectors (n_vars x n_time)
```

Run `python scripts/Validation/run_simulation.py --help` for the full CLI reference.

## Fitted parameters

`results/test fitting/` holds the fitted parameters used throughout the notebooks:

- `test {N}/HFR_fit_test{N}_*.json` — per-test membrane parameters fitted to HFR data
- `global/global_k_ca_fit_{24,32,40}.json` — global cathode reaction rate constant plus
  per-test anode exchange current density, one file per temperature group


## Reproducing the paper's figures

The notebooks under `notebooks/plotting/` and `notebooks/parameter_sensitivity/` regenerate the
figures used in the paper from `data/experimental/`, the fitted parameters above, and the
defaults in `rfbmodel1D/parameters/params.py`. Each notebook is self-contained; run cells top to
bottom. Figures are written to `figures/`.

`notebooks/plotting/lambda_membrane_profiles.ipynb` first needs its membrane water-content
profiles generated:

```bash
python scripts/utils/generate_lambda_profiles.py --tests 5 16 25 --save
```
